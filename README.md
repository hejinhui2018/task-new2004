# Harris 地层矩阵工作台

浏览器内使用的 Harris 地层矩阵（Harris Matrix）记录与校核工具：现场记录员边录入、边校核，
整理阶段直接得到从晚到早、只保留必要直接连线的矩阵，并能解释被隐藏的传递关系、
定位年代/分期矛盾、比较多套解释假设。**纯前端，无需后端**，数据保存在浏览器 localStorage。

## 运行方式

```bash
npm install        # 安装依赖
npm run dev        # 开发服务器（默认 http://localhost:5173）
npm run build      # 类型检查 + 生产构建（输出到 dist/）
npm run preview    # 本地预览生产构建
npm test           # 运行全部测试（Vitest，一次性）
npm run test:watch # 测试监听模式
```

要求 Node.js ≥ 18。

## 功能

### 录入与校核

- **地层单元**：区分 `堆积 / 切割 / 构筑` 三类，可编号、写描述、指定人工分期。
- **早晚关系**：录入“谁晚于（压着）谁”。新关系若会形成**循环**、或落在同一**等同组**内，
  不会破坏当前有效矩阵——修改被保留为“待处理修改”，侧栏与画布同时给出
  **完整矛盾链**（拟新增边 + 闭合回起点的全部已有关系/等同）。删除链上任意一条证据后，
  待处理修改的矛盾状态实时刷新，解除后一键应用。
- **等同关系**：把同一地层事件的两个记录号标记为同期；若两者之间已存在早晚关系，
  同样被拦截并给出贯穿等同类的矛盾链。等同类在矩阵中合并为一个节点。

### 矩阵生成与解释

- **传递约简**：自动隐藏可由更细关系链推出的冗余连线（如 A→C 已由 A→B、B→C 表达），
  等同类之间的平行边互不掩盖。可开关“显示隐藏线”（虚线）。
- **路径解释**：点“路径解释”后依次选两个单元，给出从晚到早的直接关系链（含等同跨越），
  解释“为什么 A 晚于 B”。点选任意隐藏边也会在侧栏显示其替代证据链。
- 分层自动布局（晚在上、早在下），**鼠标滚轮缩放、拖动画布、拖动节点**，一键重排/适应窗口。
- **播放形成过程**：滑块或自动播放，从最早层逐层“形成”到晚近层。

### 年代与分期传播

- 每个单元可录入多条出土物年代范围（公元纪年整数，公元前用负数）与人工分期。
- 沿早晚关系传播后，按等同类显示**可行最早/最晚年与分期区间**，并标明
  **由哪条证据收紧**（如“最早≥1000（[106] 影青瓷片）”）。
- 无解时定位**最小冲突证据集**：两端出土物/分期 + BFS 最短关系链；
  同一等同类内部年代相反、分期次序相反也会标出。

### 解释假设

- 一键**复制当前矩阵**建立另一套解释；不同假设中的单元按**稳定身份（id）对应**。
- 比较两套假设：相对基准的**新增、删除、反转**关系，以及等同组的**新合并/被拆开**，
  仅有一方存在的单元单列。

### 证据复核

- 对**出土物年代、人工分期、早晚关系、等同关系**建立待审变更，逐条标记为
  **保留 / 撤回 / 暂不采用**；候选变更栏集中在“复核”页，复核会话与假设一一对应。
- 系统在**隔离的候选快照**中重算等同类、传递约简、年代/分期传播与冲突证据，
  并展示与当前解释的差异：**影响单元数量、年代/分期界前后值、冲突增减**、
  等同类拆分与连线隐藏状态变化。候选**不污染当前矩阵**——顶栏另有摘要徽标，
  画布上被标记撤回的关系以橙色虚线提示（未生效）。
- **采用**把全部“撤回”作为**一条可撤销事务**写入当前假设（↶ 撤销可回退）；
  “保留 / 暂不采用”项不改动矩阵；**取消复核**丢弃全部候选。
- 撤回后若产生**悬空解释**（单元失去全部早晚/等同关联、手动布局失去等同类锚点）
  或复核目标已被删除（**无法定位**），复核页明确列出警告，绝不静默删除。
- 复核会话独立存入 localStorage（`harris-workbench-review-v1`），**刷新后恢复**；
  旧版数据没有该键，照常打开。
- 内置 **复核演示（H3 探方）** 案例：`[401] 晚于 [402] ≡ [403] 晚于 [404]` 的传递链上，
  开元通宝（700–780）与影青瓷片（1000–1080）沿链冲突；**撤回**等同 `[402]＝[403]`
  会拆分类并解除冲突链，改标**保留**则结果不变。

### 其他

- 撤销 / 重做（快照历史，`Ctrl+Z` / `Ctrl+Shift+Z`），删除单元自动清理关联关系。
- 亮 / 暗主题；所有数据自动存入 localStorage（顶栏“重置示例”可清空恢复）。
- 内置 **T1 小型发掘区示例**：生土、墙基沟槽、石砌墙基（夯土内开元通宝，720–780）、
  南北两块同期居住面（等同）、晚期排水沟沟槽、沟内回填（影青瓷片，1000–1080）、
  近代坑及坑填土、表土；其中“排水沟切入生土”是一条会被约简隐藏的间接记录，
  可直接演示隐藏线解释。

## 目录结构

```
src/
  lib/
    types.ts        领域模型（单元、关系、等同、待处理修改、复核会话、项目状态）
    equivalence.ts  并查集与等同路径
    graph.ts        商图、循环阻断与完整矛盾链、传递约简、路径解释、分层
    dates.ts        年代/分期传播、收紧证据溯源、最小冲突证据集
    review.ts       证据复核：隔离候选快照、解释差异、悬空/无法定位检测
    layout.ts       分层重心法自动布局
    hypothesis.ts   假设差异（新增/删除/反转/等同合并拆开）
    history.ts      撤销重做快照栈
    sample.ts       内置 T1 发掘区示例与 H3 探方复核演示案例
    store.ts        React store（校验拦截、持久化、复核会话与采用事务）
  components/       Canvas / RecordTab / DatesTab / ReviewTab / HypothesesTab / ChainView 等
  test/             Vitest 测试（纯逻辑 + store 集成 + App 挂载冒烟）
```

## 关键模型约定

- 关系方向统一为 `younger 晚于 older`（矩阵中箭头从晚指向早）。
- 商图：用并查集把等同单元合并为“同期类”，所有循环检测/约简/传播都在商图上进行，
  呈现时再提升为单元级证据链（类内用等同步骤连接）。
- 传递约简在无环商图上对每条边检查“绕开所有同类对直达边后是否仍可达”，
  因此平行直达边互为冗余判据时不会被误隐藏。
